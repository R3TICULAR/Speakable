Speakable Iframe Harness — Demo

Serve the repo root over HTTP (e.g. npx serve .) and open this file at /examples/harness-demo.html. Run npm run build first so dist/ exists. The harness mounts each example into an iframe via srcdoc (same-origin), injects the shared bundle, and reads results over postMessage.

Complex: Lit-style web component + interaction timeline

Loads a custom element that renders its content in an open shadow root with a <slot>, exposes a Lit-style updateComplete promise, and toggles aria-expanded on click. The harness awaits upgrade, runs a click sequence, and returns the interaction timeline.
